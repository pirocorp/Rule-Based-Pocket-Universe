# Хипотеза — Bottle Tree Numbers / Melody Memory Key

**Статус:** Силно подкрепена след S03E10
**Увереност:** ⭐⭐⭐⭐⭐ за melody/memory-key function; ⭐⭐☆☆☆ за routing/archive secondary functions.

## Теза

Числата в Bottle Tree не са само възможни години, coordinates, route IDs или logs. S03E10 показва, че те могат да бъдат прочетени/използвани като музикална последователност, която отключва children/reincarnation memory.

## Доказателства за

- Bottle Tree notes съдържат structured four-digit numbers, включително `1864` и `2659`.
- S03E06 добави same-number-set, repeated-number и mirrored/reversed-digit clues.
- Jade търси pattern/shape и в S03E10 използва числата като music data.
- Мелодията при Bottle Tree води до children appearance и memory unlock при Tabitha/Jade.

## Ограничения

- Това не доказва, че числата нямат routing/archive/shape функция.
- Това не обяснява защо Dale стига до pool wall, а Tabitha до lighthouse.
- Bottle Tree остава routing node; melody key и routing algorithm са отделни въпроси.

## Тестове

- Дали същата melody може да бъде повторена и какъв ефект има.
- Дали различни number sets дават различни melodies.
- Дали melody unlock-ва само Tabitha/Jade memories или засяга и други хора.
