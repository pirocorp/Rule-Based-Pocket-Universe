# Codex стартов промпт

Копирайте/поставете това при стартиране на нов Codex разговор за хранилището:

> Прочетете `AGENTS.md`, `CURRENT_STATE.md`, `docs/methodology.md`, `docs/handoff/CHAT_CONTEXT.md` и `docs/index.md` преди да правите каквото и да е. Това е епизод по епизод, безопасен за спойлери обратен инженеринг проект за FROM. Текущата гледана граница е записана в хранилището. Продължете съществуващата методология: Observation → Rule → Evidence → Confidence → Open Questions → Hypothesis. Не използвайте знания от по-късни епизоди и не търсете бъдещи сюжетни детайли. Когато ви кажа, че съм гледал нов епизод, първо анализирайте моите наблюдения, определете само защитими нови правила, актуализирайте бележките за епизода/правилата/хипотезите/ADR/текущото състояние и направете комит. Дръжте софтуерно-архитектурните аналогии като опционални метафори, никога не като доказателство.
